# Pi Chat Web

## Register

product

## Users

面向在本地可信工作区中使用 Pi 的开发者与演示者。他们需要在同一工作台里管理持续会话、查看 Agent 执行过程、切换模型与推理强度，并快速判断运行状态和工具结果。

## Product Purpose

Pi Chat Web 是兼顾产品演示与日常使用的本地 Agent 工作台。它保留 Pi 的 REST/SSE、会话持久化、分支、附件、工具调用与 Harness 能力，并将聊天、执行步骤和上下文检查组织为清晰、紧凑的工作流。

## Brand Personality

克制、可靠、工程化。界面应像成熟开发工具一样安静而直接，重点突出当前任务、执行状态与下一步操作。

## Anti-references

避免压抑的重度深色侧栏、霓虹效果、无语义渐变、装饰性人物插画、虚构统计、营销口号、过大的控件、层层嵌套卡片，以及与本地产品事实不符的云端协作或安全承诺。

## Design Principles

1. 会话是主线，连续工具调用以 Warp Blocks 风格的 Run Group 组织。
2. 控制区保持紧凑，模型、思考深度和权限按需展开，不与正文争夺注意力。
3. 状态色只表达运行、成功、失败、警告和选中等明确语义。
4. 保留所有核心能力，次要控制仅在响应式布局中收纳。
5. 标准操作使用熟悉的产品界面模式，减少学习成本和视觉噪声。

## Accessibility & Inclusion

正文对比度至少 4.5:1，正文不小于 14px，移动端触控目标不小于 44px。支持键盘操作、清晰的非边框选中反馈、reduced-motion、亮暗主题与安全区，不以颜色作为唯一状态信号。
